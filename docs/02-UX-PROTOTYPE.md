# 页面原型与交互说明

## 1. 信息架构
- `/` 首页/快速创作
- `/create/{projectId}` Song Workspace
- `/library` 我的作品
- `/song/{songVersionId}` 歌曲结果
- `/share/{token}` 分享页
- `/admin/benchmark/{runId}/review` 盲听评分

## 2. 首页
核心区域：品牌说明、主题输入框、风格、人声、情绪、时长、开始创作按钮。

示意：
```text
┌────────────────────────────────────┐
│ AI MUSIC                           │
│ 把一个想法变成一首歌              │
│ [ 描述主题、故事、情绪……       ] │
│ 风格 [自动▼] 人声[自动▼] 时长[3m]│
│          [开始创作]                │
└────────────────────────────────────┘
```

## 3. Song Workspace
建议三栏：左侧创作设置；中间歌词编辑；右侧 AI 理解、生成任务和版本。

```text
┌──────────┬──────────────────┬──────────────┐
│创作设置  │ 歌词编辑器       │ AI理解结果   │
│主题      │ [Verse 1]        │ 风格/情绪    │
│风格      │ ...              │ BPM/人声     │
│人声      │ [Chorus]         │ 能量走向     │
│情绪      │ ...              │              │
│时长      │                  │ 生成进度     │
│          │ [保存] [AI改写]  │ 68%          │
│[生成歌曲]│                  │ 版本列表     │
└──────────┴──────────────────┴──────────────┘
```

极速模式只展示用户能理解的“华语流行 / 怀旧 / 温暖男声 / 平静→高潮”；专业模式再展示 BPM、Key、配器和结构。

## 4. 生成状态
阶段文案：QUEUED=正在排队；PREPARING=正在准备你的创作；MUSIC_GENERATION=AI 正在作曲并演唱；COMPLETED=歌曲已经完成；FAILED=生成失败。

进度条属于阶段性体验反馈，不伪装成模型真实百分比；成功只在 Provider 明确完成并且音频入库成功后显示 100%。

## 5. 歌曲结果
展示封面占位、标题、播放器、歌词、版本、重新生成、下载、分享。若有真实时间戳，可实现逐词/逐句歌词高亮。

## 6. 歌词编辑
支持 section 级编辑；AI 局部改写时仅修改选中 section。每次用户保存或 AI 重写均创建新的 LyricsVersion，不覆盖历史版本。

## 7. 异常交互
- Provider 超时：提示“生成时间较长，正在重试”，不丢任务。
- 最终失败：展示可理解错误并允许重新生成。
- SSE 断开：自动恢复或降级轮询 `/tasks/{id}`。
- 刷新页面：从数据库恢复 Project、版本与任务状态。

## 8. Benchmark 盲听页
只展示 Track 随机编号，不展示 Provider/Model。评分：中文人声、旋律、歌词准确、编曲、Prompt 遵循、音质、是否愿意发布及备注。保存后自动进入下一首。
